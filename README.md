# Control de horas

Páginas de apoyo para la app de control de horas:

- `index.html`: lanzador para instalar la app en la pantalla de inicio del celular, con su ícono.
- `app.html`: muestra la app de Google a pantalla completa (sin el cartel de Google) y recuerda el celular para no pedir el PIN cada vez.
- `config.js`: **el link de la app** (termina en `/exec`). Si cambia, se edita solo ahí.
